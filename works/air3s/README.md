# AIR 3S · Detail Edition 04

双击 **启动预览.bat**。需要 Python 3；启动器自动选择 8765–8775 的空闲本地端口并打开浏览器。关闭服务窗口或停止 Python 进程即可停止服务。

本项目仅使用 HTML、CSS、JavaScript 和本地 Three.js 0.170.0。所有模型与文字贴图由代码生成，无外部 3D 模型。网络字体加载失败时使用系统字体。

## 细节版改动

- Three.js + CSS + GLSL：以程序化 PBR 表面和独立镜片着色器呈现磨砂粗糙度、镀膜反射与拆解轮廓高亮，环境反射同样由代码生成。
- 对照 DJI 官方云台近照，改为上下梯形内凹镜窗、遮光腔、内置镜片、侧轴、dji / E70 / E24 铭文。
- 机臂采用变化截面；电机改为带散热开口的型面外壳，补充铜线、轴承和紧固件。
- 接缝贴合曲面；后部感知镜头修正为后向布置。
- 新增“聚焦细节”，单独显示并放大所选部件；“返回整机”恢复全机。
- 重做宽肩收尾的连续机身曲面；上壳、中框、下壳独立分层拆解。
- 依照官方概览布置前向 LiDAR、视觉传感器、上部长焦/下部广角双摄、云台支架、下视窗口。
- 重做贴合机尾轮廓的电池，补充卡扣、电量灯、按键、USB-C 和 microSD 外观。
- 四组独立铰接机臂，前臂落地腿、动力舱和后掠双叶桨；橙色桨尖与实物外观相呼应。
- 新增折叠/展开以及透视、正面、顶部、侧面标准视角。
- 保留六类部件点击、独立/全部拆解、连续拆解滑块、标签总开关与逐项开关、自由旋转缩放、自动旋转、帮助和手机布局。
- 保留起降、WASD 移动、↑↓ 升降、Q/E 转向、触屏按钮、巡航、返回起点、高度/速度/航向/时间显示。

飞行模式自动展开并组装，阻止飞行时拆解。重置退出飞行模式；标签显隐偏好保留。部件标签设置位于右侧可滚动面板的底部。

## 参考资料与精度

用户提供的 `DJI_Air_3S_Codex_Reference_Pack.zip` 明确注明内含 PNG 为 AI 生成示意，不是官方正投影图或工程图。本页用其辅助理解外观层次，并用 DJI 官方规格、用户手册及独立实物照片交叉核对。

- 官方规格：https://www.dji.com/air-3s/specs
- 官方手册：https://dl.djicdn.com/downloads/DJI_Air_3S/UM/20250324/DJI_Air_3S_User_Manual_v1.0_en.pdf （概览第 14 页）
- 实物机臂维修照片：https://i.ebayimg.com/images/g/B9QAAOSwXRNngNPK/s-l1200.jpg
- 实物折叠机与配件照片：https://media.foto-erhardt.de/images/product_images/popup_images/dji-air-3s-dji-rc-n3-172897342106040304.jpg

仅作为研究参考，不在交付页面中嵌入这些第三方照片或手册。

模型作者单位为 65 mm，Three.js 场景采用放大的展示单位；+X 向右、+Y 向上、−Z 为机头。`air3s-model.js` 对展开且不含螺旋桨的模型外包围盒按官方 266.11 × 325.47 × 106 mm（长×宽×高）做一次比例校准。数值验证的是整体外包围盒，不表示局部表面、铰链、桨叶、接口或内部结构达到工程精度。折叠姿态是示意，未声称匹配官方折叠尺寸。

拆解路径为演示布局，不代表真实维修顺序；中框是结构示意，未虚构可验证的电路板。飞行采用简化运动学，显示的是演示状态，非 DJI 飞控或空气动力学仿真。45 分钟续航为官方实验条件数据。

## 文件

- `air3s-model.js`：程序化几何、铰接、拆解、尺寸基准与标签锚点。
- `app.js`：渲染、灯光、镜头、拾取、面板和模式状态。
- `flight.js`：飞行演示。
- `surface-glsl.js`：自编 GLSL 表面/镜片着色器与程序化演播室反射环境。
- `validation-detail.txt` / `validation-v4.json`：浏览器验证与包围盒数值。
- `vendor/LICENSE`：Three.js MIT 许可证。

本轮额外比对 DJI 官方产品页中云台正面和前下方近照：https://www.dji.com/air-3s 。未嵌入第三方照片作为模型贴图。局部外形仍为手工程序化近似，不声称已经完全还原官方实物。
